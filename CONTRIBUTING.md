# 🤝 Contributing to YOLOv8 + YOLOv5 Computer Vision Suite

Thank you for your interest in contributing! 🚀  
Whether you're fixing a bug, adding a new feature, improving documentation, or sharing a cool demo — **all contributions are welcome and appreciated**.

This project is beginner-friendly and actively maintained. Every meaningful PR gets a shoutout!

## Why Contribute?
- Get real-world open-source experience (great for resumes & LinkedIn)
- Help thousands of developers learning computer vision
- Your name permanently featured in the repo (with GitHub profile link)
- I personally review & merge PRs fast (usually <24h)

## How to Contribute

### 1. Found a Bug or Have an Idea?
- Open an **[Issue](https://github.com/ImdataScientistSachin/yolov5-yolov8-computer-vision/issues)** first
- Clearly describe the bug or feature request
- Add screenshots/GIFs if possible (especially for tracking or detection issues)

### 2. Want to Fix or Add Something? (PR Workflow)

```bash
# 1. Fork the repo (click "Fork" button at top-right)
# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/yolov5-yolov8-computer-vision.git
cd yolov5-yolov8-computer-vision

# 3. Create a descriptive branch
git checkout -b fix/loitering-timer or feature/add-byte-track

# 4. Make your changes (code, docs, notebooks, assets)

# 5. Test your changes!
#    → Run the Live_Tracking.ipynb notebook
#    → Make sure no errors on CPU/GPU

# 6. Commit with a clear message
git commit -m "fix: increase loitering threshold to 15s" 
#        or "feat: add ByteTrack integration + demo GIF"

# 7. Push and open a Pull Request
git push origin your-branch-name


Difficulty,Ideas (You’ll get extra ⭐ if you do these!)

⭐ Easy,"Fix typos in README/docs
Add better comments in notebooks
Improve folder organization"

⭐⭐ Medium,"Add new demo GIFs/videos
Improve Streamlit dashboard
Add new YOLOv8 model sizes (yolov8m, yolov8x)"

⭐⭐⭐ Hard,"Integrate ByteTrack / BoT-SORT
Add person re-identification (ReID)
Export to TensorRT + benchmark script
Add multi-camera stitching"


4. Code Style & Best Practices

Follow PEP 8 (Python style guide)
Add comments for complex parts
Keep notebooks clean and reproducible
Include before/after screenshots or GIFs in your PR description

5. Pull Request Guidelines

One feature/fix per PR (keeps reviews fast)
Reference the issue number (e.g., Closes #12)
Be friendly — this is a learning space! 😊

Example PR title:
feat: add ByteTrack integration with 15% better tracking accuracy


After Your PR is Merged

You’ll be added to the Contributors Hall of Fame (coming soon in README)
I’ll share your contribution on LinkedIn/X with credit
You get permanent bragging rights! 🎉

Need Help?

I reply fast and love mentoring contributors
